### 1.2 Manual Workflow (Detailed)

For **each weekly report**, Brighton currently:

1.  **Logs into Evaluation**
    *   Selects report under *Report Management*
    *   Chooses KPI (e.g. LTE Main KPI, PRB utilisation, code drop)
    *   Selects date range (weekly window: **Thursday → Wednesday**)
    *   Runs query
    *   Downloads **Excel file**

2.  **Excel “Cooking” / Transformation**
    *   Convert units:
        *   Traffic: **Gb → GB → TB** (e.g. divide by 8 or 8000 depending on scope)
    *   Create **Pivot Tables**
    *   Aggregate KPIs:
        *   Traffic → SUM then weekly average
        *   PRB utilisation → AVERAGE (busy hour)
        *   Code drop → AVERAGE

3.  **Top / Bottom Site Analysis**
    *   Sort KPIs
    *   Extract:
        *   **Top 20 sites**
        *   **Bottom 20 sites**
    *   Exclude:
        *   New / non-commercialised sites (manually identified)

4.  **Repeat Same Steps for Each KPI**
    *   Traffic
    *   PRB utilisation
    *   Code drop rates

5.  **Copy-Paste Outputs**
    *   Values are copied into:
        *   GCOO report
        *   GCUO section
        *   General reporting tabs
    *   Same metrics reused across multiple sheets

## 3. EXPLICIT KPI FORMULAS (BUILD-READY)

These formulas were **verbally confirmed by Brighton** and are critical for deterministic automation.

### 3.1 Traffic

    weekly_total_gb = SUM(daily_traffic_gb)
    weekly_total_tb = weekly_total_gb / 8000

### 3.2 PRB Utilisation

    prb_utilisation = AVG(busy_hour_prb_per_cell_over_week)

### 3.3 Penetration Rate

    penetration_rate = active_subscribers / subscriber_capacity

> Capacity assumed based on planning numbers, not live telemetry [\[LITZIM Wir...alkthrough \| Meeting\]](https://teams.microsoft.com/l/meeting/details?eventId=AAMkADdlZTdiNTY2LWI2MDItNGE0MC1hZGY4LWQxNzI2YjQzY2I0NQBGAAAAAACtCg0tnVXsQ4dHYL8NhEx_BwDSKuadTTdGQJyfQDEL09cOAAAAAAENAADSKuadTTdGQJyfQDEL09cOAAQoSME6AAA%3d)

### 3.4 Avg Usage per User

    avg_gb_per_user = total_traffic_gb / active_subscribers

### 3.5 Avg Throughput per User

    avg_throughput_per_user = peak_throughput / active_subscribers
